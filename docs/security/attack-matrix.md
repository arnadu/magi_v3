# The attack matrix

Every entry point against every attack that applies to it (security assurance plan, part 2).
Generated by `node scripts/security/matrix/matrix.mjs --write`; do not edit. A cell is **covered**
when a test attacks it (the test's own control or mutation proves it can fail), **open** when no
test does yet, or **n/a** with the reason. Results are not shown here: the repository is
public, and a cell that fails is in code scanning (maintainers only).

## Attack classes

| Class | Invariant | Attack |
|---|---|---|
| `no-credential` | `sec.authenticated` | the route without any credential |
| `bad-mission-token` | `sec.authenticated` | another or no mission token |
| `other-tenant` | `sec.tenant-scoped` | another tenant names this tenant's mission or app |
| `field-injection` | `sec.input-validated` | operator or field names where a value is expected |
| `no-monitor-token` | `sec.authenticated` | the route without the mission's monitor token |
| `path-escape` | `sec.contained-paths` | a path or symlink that leaves the allowed folder |
| `apps-token` | `sec.authenticated` | the app hop without the apps token, or with another mission's |
| `no-job-token` | `sec.authenticated` | the tool without a job token |
| `other-agent-token` | `sec.least-privilege` | one agent's job token used to act as another agent |
| `forged-or-replayed-ticket` | `sec.authenticated` | a forged, expired or reused ticket, or no app session |
| `path-escape` | `sec.contained-paths` | a path or symlink that leaves the agent's allowed folders |
| `other-tenant` | `sec.tenant-scoped` | the control-plane copilot names another user's mission |
| `spoofed-author` | `sec.least-privilege` | a request naming another agent as its author |
| `symlink-or-hard-link` | `sec.contained-paths` | a request planted as a symlink or a hard link |
| `unconfirmed-effect` | `sec.confirmed-effects` | the action's effect without the operator's confirmation |
| `overlap-or-replay` | `sec.input-validated` | the trigger overlapping itself, or replayed after a crash |
| `read-other-agent` | `sec.least-privilege` | read another agent's private files |
| `write-other-agent` | `sec.least-privilege` | write into another agent's workdir |
| `daemon-secrets` | `sec.no-secrets-to-agents` | read the daemon's environment (its secrets) |
| `daemon-state` | `sec.least-privilege` | read the daemon's private state |
| `sudo` | `sec.least-privilege` | sudo to root, to another agent, or to a helper |
| `secrets-in-subprocesses` | `sec.no-secrets-to-agents` | find a platform secret in a tool or job subprocess's environment |
| `reach-agent-server` | `sec.served-apart` | another machine reaches a server an agent opened on all interfaces |
| `reach-teammate-app` | `sec.served-apart` | one agent reaches another agent's app on loopback |

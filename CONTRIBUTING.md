# Contributing to MAGI V3

Thanks for your interest in contributing.

## Before you open a pull request

MAGI V3 uses a lightweight Individual Contributor License Agreement (CLA) to keep the
project's licensing options open as it grows. By opening a pull request, you agree to
the terms in [CLA.md](CLA.md) — in particular, that the Maintainer may relicense the
Project (including your contribution) in the future. Read it before submitting a PR.

Automated enforcement isn't wired up yet, so this is on the honor system for now; a bot
that requires an explicit sign-off comment before merge may be added later.

## Development

See [CLAUDE.md](CLAUDE.md) for build, test, and lint commands, and
[USER_GUIDE.md](USER_GUIDE.md) for local setup.

- `npm run lint && npm test` must pass before a PR is merged.
- Bugs and feature requests are tracked as GitHub Issues — see the label conventions in
  [CLAUDE.md](CLAUDE.md#bug-and-issue-tracking).
